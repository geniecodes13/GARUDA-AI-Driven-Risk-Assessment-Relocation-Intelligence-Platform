# GARUDA Demo Script

1. Open the Streamlit dashboard and observe the black/white decision cockpit.
2. Select a high-risk habitation such as Bhatwari or Jhala.
3. Review hazard components, vulnerability breakdown, and risk score.
4. Inspect relocation priority: immediate, short-term, or medium-term.
5. Compare the set of candidate safe sites and review capacity limits.
6. Confirm resource readiness and identify critical shortages.
7. Use the scenario slider to simulate a 60% or 70% relocation case.
8. Ask the AI assistant why the village is prioritized or which site has the largest carrying capacity.
9. Record officer review and approval status as a decision-support workflow.

This demonstrates the core chain: risk assessment -> priority -> safe site discovery -> capacity -> resources -> AI explanation.
